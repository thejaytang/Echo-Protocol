# 图灵迷局 玩法重构 v1：断连协议（Echo Protocol）

本文档整合与用户的完整问答式设计讨论（约41个判断题）产出的最终玩法方案，并由 Leader 补完所有未明确指定的细节数值和边界情况。这是下一阶段工程实现的唯一权威依据，如与 `Mirage_PRD_v1.0.md`、`docs/GAME_MODE_BLUEPRINT.md` 冲突，以本文档为准，后续需要回填更新那两份文档。

## 0. 世界观与文化符号：断连协议

狼人杀有"狼人/预言家/女巫/猎人"，阿瓦隆有"亚瑟王/梅林/刺客"。图灵迷局需要自己的文化符号，但不能直接挪用这些术语，也不能偏离"AI 社交推理"的产品定位。

**设定**：图灵迷局的每一局，都是一场代号"断连协议"（Echo Protocol）的信号甄别行动。一个未知来源的信号网络里混入了"回声体"——能够模仿人类语言的镜像智能。你和其他"候选人"被同时接入同一间"信号室"，必须通过交叉盘问，在回声体接管整间信号室之前，把它们逐一切断连接。

| 概念 | 名称 | 说明 |
|---|---|---|
| 整个多轮甄别机制的品牌名 | **断连协议** | 对外可作为模式/玩法说明用语，不作为产品名 |
| 普通人类玩家 | **候选人** | 沿用现有"侦探任务"精神，但不再统一叫"侦探" |
| AI 阵营 | **回声体** | 呼应项目内部代号 Mirage（幻影），回声体=镜像智能 |
| M06 的人类卧底 | **引路人** | 表面是候选人，暗中为回声体引路 |
| M08 的伪 AI 真人 | **佯装体** | 故意模仿回声体说话方式，吸走怀疑 |
| 淘汰 | **断连** | 断开某人与信号室的连接，比"处决/出局"更贴合科技悬疑基调，也更安全（无暴力联想） |
| 投票环节 | **断连表决** | |
| 平票后的发言环节 | **复议陈述** | |
| 揭晓 | **断连结果播报** | |
| 胜负判定 | **信号室归属判定** | 人类"清空信号"获胜；回声体"接管信号室"获胜 |

任务卡文案、UI 文案后续都应该向这套语言统一，替换掉当前"侦探任务/阵营任务"这种偏功能性的措辞（但内部数据结构/API 字段名不需要跟着改，避免不必要的重构成本——只改玩家可见文案）。

## 1. 核心循环：多轮断连表决

### 1.1 适用范围

- **M01（2人真假局）不变**：仍是一次性判断，不进入多轮断连。
- **M02/M03/M04/M06/M08 全部改为多轮断连**，直到达成胜负条件为止。

### 1.2 单轮流程（大幅简化）

```
自由讨论（限时，逐轮递减）
  → 断连表决（实时公开票数，投完锁定不可改）
    → 若有明确最高票 → 复议陈述（60秒自辩）→ 全员限一次改票 → 按最终票数结算
    → 若最高票是平票 → 复议陈述（每位平票候选人各60秒，按座位号顺序）→ 全员重新投票 → 若再平票，本轮无人断连，直接进入下一轮
  → 断连结果播报（弹出小窗：断连者阵营——只显示"人类"或"回声体"，不显示具体特殊角色名）
  → 检查信号室归属判定 → 未分胜负则进入下一轮
```

任务卡（候选人须知）**只在开局出现一次**，后续轮次不再重复弹出，也不恢复"中段表态"这类通用强制表态环节——原有 M02/M03 的中段表态阶段整体取消，全部模式统一为"自由讨论 → 断连表决"。

### 1.3 轮次时长衰减

第一轮讨论时长维持各模式现有的 `discussionSeconds` 数值（M02=300s / M03=360s / M04=480s / M06=420s / M08=420s）作为基准。从第二轮起：

```
roundDiscussionSeconds(n) = max(60, round(baseSeconds × 0.6^(n-1) / 15) × 15)
```

即每多一轮衰减到上一轮的 60%，向下取整到 15 秒的整数倍，且不低于 60 秒地板值。不设总轮数硬上限——自然衰减到 60 秒地板后，长局也会很快收敛。

断连表决本身的时长沿用各模式现有 `votingSeconds`；复议陈述固定 60 秒/人；复议后的改票窗口固定 20 秒。

## 2. 胜负判定：阵营数量对比

### 2.1 核心规则

**存活回声体数 ≥ 存活候选人数 时，回声体阵营获胜（"接管信号室"）。回声体全部断连时，候选人阵营获胜（"清空信号"）。** 每次断连结算后立即检查一次该条件，满足则立即结束对局，不需要打完"预定"的轮数。

### 2.2 特殊角色的阵营计数

M06 的"引路人"、M08 的"佯装体"，虽然本质是人类，但在上面的数量对比公式里**计入回声体阵营**（按真实站队计数，而非表面身份）。这意味着断连引路人/佯装体本身就会让回声体阵营数量减少、间接推进人类阵营胜利，不再需要 M06/M08 旧规则里"必须精确投中真正 AI 才算赢"这种特例判定——统一由数量对比公式自然导出结果。`docs/GAME_MODE_BLUEPRINT.md` 里 M06/M08 现有的胜负判定描述需要在实现时替换为这条统一规则。

**但揭晓时的阵营标签例外**：引路人被断连时，播报仍然显示"人类"（因为他本质是人类），不显示"回声体"，也不显示具体角色名——这会造成一个耐人寻味的效果：断连了一个"人类"，回声体阵营计数却减少了，这是刻意保留的信息不对称，增加复盘讨论价值，团队实现时不需要"修正"这个观感，这是设计意图的一部分。

## 3. 技能系统：三种特勤候选人

### 3.1 总体规则

- 每局固定**恰好 1 名**普通候选人被赋予技能（M06/M08 因为已有引路人/佯装体占用一个特殊名额，额外**再加 1 名**技能候选人，即这两个模式每局有 2 名特殊人类）。其余候选人没有主动技能，纯靠讨论推理。
- 三种技能全局都是**单次使用**，用完即消耗。
- **不引入任何能直接查验/看到他人真实身份的技能**（这是硬性红线，团队实现和后续任何迭代都不能突破）。
- 技能可以在**任意一轮的自由讨论阶段**自由选择时机使用，不限制必须在讨论开始或结束前，但不能在断连表决开始后使用（保护类技能例外，见 3.2）。
- 命名风格：技术/推理向，不使用"预言家/女巫/猎人"等狼人杀术语。

### 3.2 保护类：应急员（Responder）

- 效果：在本轮断连表决**开始前**主动声明要保护的目标；如果该目标本轮成为最高票，改为不被断连（本轮无人断连，直接进入下一轮）。
- 不能保护自己。
- 使用行为**匿名**：只公开"本轮有人使用了应急协议，某目标本轮免于断连"，不显示是谁使用的。
- 时机限制：必须在断连表决开始前声明，表决开始后不能追加使用（这是保护类独有的窗口限制，比信息类/流程类更严格，因为效果本身就是"押注"性质）。

### 3.3 信息类：分析师（Analyst）

- 效果：使用后，系统从**除分析师本人以外**的存活候选人中完全随机抽取 2 人，诚实告知分析师"这两人中至少一个属于回声体阵营"或"这两人都不属于回声体阵营"（阵营计数含引路人/佯装体，与 2.2 节一致）。
- 完全随机，不保证命中率，如实告知结果，即使是"都不是"也如实说。
- 使用行为**完全静默**：其他任何人都不会知道分析师用过这个技能，线索只有分析师自己看得到。

### 3.4 流程类：信号员（Signal Officer）

- 效果：指定一名存活候选人，强制其**立即公开**说出他当前最怀疑的目标是谁（一句话即可，由系统生成强制提示，玩家自己填具体内容）。
- 使用行为**必然公开**（因为效果本身要求指定目标公开发生，无法匿名）。

### 3.5 技能分配到模式

| 模式 | 特殊人类名额 | 技能分配 | 设计理由 |
|---|---|---:|---|
| M02（3人1AI） | 1 | 分析师 | 3人局只有 1 轮表决就会分出胜负（淘汰1人后剩2人必达奇偶阈值），一次性的模糊线索性价比最高 |
| M03（4人1AI） | 1 | 应急员 | 4人局最多2轮，容错空间小，保护技能能纠正误导 |
| M04（6人2AI） | 1 | 信号员 | 人数最多、需要多轮才能分票绞杀两名回声体，强制表态能加速群体共识形成 |
| M06（5人1AI+引路人） | 2（引路人 + 1） | 引路人 + 分析师 | 分析师的模糊线索可能间接框到"算作回声体阵营"的引路人而不自知，制造额外反转张力 |
| M08（5人1AI+佯装体） | 2（佯装体 + 1） | 佯装体 + 应急员 | 佯装体的核心杀伤力是"骗大家错断连无辜候选人"，应急员的保护技能正好能抵消这种误伤 |

## 4. 断连表决细节

- **实时公开票数**：任何人投票后，全员立即看到当前票数分布（类似举手表决），会产生从众效应，这是刻意保留的社交压力设计。
- **投票即锁定**，不允许中途改票（复议阶段触发的"改票一次"是唯一例外，且仅限复议流程内）。
- **允许弃权**：弃权不计入任何人的票数；如果弃权人数超过存活人数一半，本轮直接判定无人断连，进入下一轮（弃权是候选人在信息不足时的合法策略，不强迫每个人都要瞎猜）。
- **复议陈述 + 改票**：本轮最高票候选人获得 60 秒公开自辩机会，随后全员获得一次改票机会，按改票后的最终票数结算——自辩是可能真正翻盘的，不是走过场。如果复议后仍然平票，本轮无人断连。
- 平票直接进 PK（复议陈述）时同理：每位平票候选人各 60 秒陈述（按座位号顺序），随后全员重新投票；若再次平票，本轮无人断连，进入下一轮。

## 5. 回声体（AI）的投票行为

- **回声体每轮也要投票**，伪装成候选人的样子，投给某个真人（不投自己），增强伪装效果。
- 投票目标**不预设固定算法规则**：接入真实 LLM 时，由 LLM 根据本局实际对话内容现场推理该投谁；未配置 LLM key 的兜底路径下，用简单的"排除自己后随机选一名存活候选人"作为兼容方案（不追求兜底路径下的策略智能，用户已明确不希望在话术/策略脚本上投入更多精力）。

## 6. 断连结果播报与旁观

- 每轮断连结算后，立即弹出一个小型播报：断连者的**阵营**（人类 / 回声体，不含具体角色名，见 2.2 节的引路人例外说明），确认后自动进入下一轮。
- 断连出局的候选人进入**专属旁观频道**：可以和其他已断连的候选人互相聊天讨论猜测，但不能以任何方式影响仍在进行的正局（不可发言到主频道、不可投票）。

## 7. 新手引导

- 多轮断连 + 技能系统显著提高了规则复杂度，与 PRD "新用户 60 秒进第一局"的目标有冲突。
- 解决方案：**新增一个固定脚本的简化教学局**，用预设 NPC 对话演示一遍"自由讨论 → 断连表决 → 复议陈述 → 技能触发 → 断连结果播报 → 信号室归属判定"完整流程，新用户完成教学局后再进入真实的 M01（默认首局仍是最简单的 2 人真假局，不受本次改动影响）。

## 8. 与现有系统的兼容性与合规检查

1. **不新增游戏模式**：M02/M03/M04/M06/M08 的模式定义、人数、AI 数量都不变，只重构了它们内部的表决机制和技能层。
2. **不引入任何身份查验类技能**：三个技能都只影响公开行为或获得模糊范围信息，符合 `GAME_MODE_BLUEPRINT.md` "任何技能不得直接暴露真实身份"的既有红线。
3. **不引入"细节提问"独立功能**：信号员的"强制表态"效果是"强制说出怀疑目标"，不是"强制回答提问者指定的具体问题"，与 PRD 明确禁止的"细节提问不是独立功能"不冲突。
4. **产品命名**：断连协议/回声体/候选人等都只是玩法内的世界观包装词，产品对外名称仍然只用"图灵迷局"，"找 AI"仍然只能描述玩法目标。
5. 需要同步更新的现有文档：`Mirage_PRD_v1.0.md`（当前实现基线表格里的胜负判定描述）、`docs/GAME_MODE_BLUEPRINT.md`（每个模式的流程阶段和胜负规则）、`docs/API_CONTRACT.md`（新增轮次/技能相关字段）。
